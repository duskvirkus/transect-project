● Before jumping into openspec, a quick note on the Wikipedia API question:

  Recommendation: Use Open-Meteo instead of Wikipedia.

  Wikipedia stores climate data as wikitext tables embedded in city articles —
  parsing that reliably across 10 arbitrary global stations would be fragile and
   inconsistent (many smaller cities lack climate tables entirely). Open-Meteo
  is a much better fit:
  - Free, no API key required at all (eliminates the key input UI entirely)
  - Climate API returns monthly temp/precip normals from ERA5 reanalysis data
  - Works for any lat/lng on Earth — perfectly generalizable
  - Returns structured JSON — no parsing required
  - Fully client-side, no backend needed

  That said, I'll design for Open-Meteo. If you want Wikipedia anyway let me
  know before I write the tasks.
